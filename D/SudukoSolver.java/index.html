How it works

This project uses a Backtracking Algorithm to solve a 9 × 9 Sudoku puzzle.

  1. Find an empty cell.
  2. Try numbers from 1 to 9.
  3. Check whether the number is valid.
  4. Continue recursively.
  5. Backtrack if the choice does not work.
